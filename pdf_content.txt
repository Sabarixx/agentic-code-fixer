​Option C — Multi-Agent Code-Fix System:​
​Week-by-Week Execution Guide​
​Scope decision (locked before Week 1):​​The system​​takes a function-level specification​
​(name, signature, docstring, constraints) and a hidden test suite, then runs a Planner → Coder​
​→ Tester loop — with a Refactor pass after tests first pass — until the code passes all tests or​
​the iteration cap is hit. The evaluation domain is a fixed set of​​8 curated function specs​
​(LeetCode/DSA-style — this doubles as reusable material for your own DSA practice). This​
​bounded domain is what makes Option C tractable solo in 8 weeks; do not expand it to arbitrary​
​codebases or multi-file projects.​
​Total duration:​​8 weeks.​​Owner of every task below:​​you, solo.​​Weekly time budget​
​assumed:​​~15 hrs weekday (3 hrs × 5) + ~8–10 hrs weekend​​= ~23–25 hrs/week.​
​Architecture decision (make this Week 1, Day 1, don't revisit later):​​Implement the three​
​roles (Planner, Coder, Tester) as three distinct LangGraph nodes sharing one typed state object​
​—​​not​​as separate AutoGen/CrewAI agents with independent​​memories. This is materially​
​simpler to debug solo, still satisfies "multi-agent" per course terms (distinct roles, distinct​
​prompts, distinct responsibilities, coordinated via graph edges), and reuses the LangGraph skill​
​path from the course.​
